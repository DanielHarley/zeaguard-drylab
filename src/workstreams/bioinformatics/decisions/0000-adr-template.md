## Classificação das evidências

1. `diretamente demonstrado`: explicitamente presente em uma fonte primária, input imutável, manifest, código ou observação direta.
2. `derivado/computado`: produzido por uma transformação computacional declarada a partir de inputs registrados.
3. `inferido/interpretado`: interpretação que depende de pressupostos ou julgamento científico.

Não atribua uma categoria mais forte do que a evidência permite. Uma execução bem sucedida não demonstra validade científica. Reprodutibilidade computacional não estabelece validade científica. Uma associação computacional não deve ser descrita como identidade confirmada sem evidência suficiente. Ausência de evidência permanece `UNRESOLVED`.
